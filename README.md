# Laboratorios y ejemplos prácticos con PySpark

Repositorio de pruebas y experimentos con PySpark. Aquí comparto mi exploración y aprendizaje sobre Spark, trabajando con notebooks que incluyen análisis exploratorio de datos, comparaciones entre RDDs y DataFrames, y otros ejemplos prácticos para profundizar en el procesamiento distribuido.

Este repositorio está pensado como un espacio de aprendizaje y práctica, por lo que los códigos y datos son ejemplos para entender mejor PySpark y sus funcionalidades.
